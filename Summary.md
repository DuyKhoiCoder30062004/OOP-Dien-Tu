# OOP Console-based Electronic Store Management System

A console-based application built with **Java** to manage an electronic store.  
This project was developed as an academic assignment to practice **Object-Oriented Programming (OOP)** principles.

---

## 📌 Project Information
- **Team size:** 4  
- **Role:** Backend Developer  
- **Duration:** Mar 2026 – Present  
- **Language:** Java  

---

## 📌 Overview
The system is designed to manage store operations such as product inventory, customer data, and sales transactions.  
It follows OOP principles with UML-driven design to ensure maintainability and scalability.

---

## 📌 Features
- <mark>Menu Navigation</mark> for system functions  
- <mark>File I/O Handling</mark> with text files  
- <mark>CRUD Operations</mark> (add, edit, delete, search)  
- <mark>Dependency Relationships</mark> between entities in UML Class Diagram  

---

## 📌 System Design
- Designed <mark>UML Class Diagram</mark> to model system entities and dependencies  
- Implemented maintainable <mark>OOP Structure</mark>
